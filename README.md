# The Thirteenth Dimension

A 3D third-person arena action game that runs in the browser (Three.js, no build step).

Play: https://alhjmiiy-netizen.github.io/thirteenth-dimension/

- Desktop: WASD move · J / Space / left-click attack · K Lightning Burst · Shift / L Phase Dash · U Void Vortex · Q Potion · drag mouse or ←/→ to turn the camera · Esc pause
- Phone (landscape): left stick to move, big button to attack (hold for combos), skill buttons on the right, drag the screen to turn the camera

Add `?q=low` to the URL for a lighter graphics mode.
